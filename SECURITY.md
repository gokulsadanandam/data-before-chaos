# Security

* Secrets (the HMAC token key) live in Azure Key Vault and are read at run time. The
  `local_dev_key` in `config/pipeline.yaml` is for local tests only and is not a secret.
* Do not put real personal data in this repository, issues or notebook outputs. All
  test data is generated by `tools/generate_synthetic_data.py`.
* Report a vulnerability or data exposure to the team lead privately, not in an issue.

Controls in the solution are listed in `fabric/governance/security_and_privacy.md`.
